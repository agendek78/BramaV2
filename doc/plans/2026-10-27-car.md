# Moduł `:car` (Android Auto) — plan implementacji

> **Dla wykonawców agentowych:** WYMAGANY SUB-SKILL: superpowers:subagent-driven-development (zalecany) albo superpowers:executing-plans, zadanie po zadaniu. Kroki mają składnię checkboxów (`- [ ]`).

**Cel:** Ekran Android Auto ze stanem i OTWÓRZ/ZAMKNIJ oraz powiadomienie w samochodzie z przyciskiem OTWÓRZ, gdy telefon wykryje bramę w zasięgu.

**Architektura:** Moduł `:car` (Android library) zależy tylko od `:domain`. Logika — model ekranu `carPane` i polityka powiadomienia `CarNotificationPolicy` — to czysty Kotlin testowany na JVM. `CarAppService`, `Session`, `Screen` i powiadomienia są cienką warstwą nad Car App Library. `:app` dostarcza repozytorium przez interfejs `CarDependencies`.

**Stos:** Kotlin 2.2.10, AGP 9.2.1, `androidx.car.app:app` i `app-projected` 1.7.0, coroutines 1.10.2, JUnit 4.

**Specyfikacja:** `doc/car_design.md` (zatwierdzony), `doc/PLAN_I_SPECYFIKACJA_BRAMY.md` 1.4 (3, 4.3, 5), `domain/.../UiMessages.kt` (`car`), `app/.../BramaApp.kt`.

## Ograniczenia globalne

- `:car`: `com.android.library`, `namespace = "com.agendek.bramav2.car"`, `compileSdk = release(37)`, `minSdk = 34`, Java 11 — jak `:ble`.
- Teksty wyłącznie przez `Texts` (lista zamknięta spec 3); w samochodzie `Texts.car` — jedynie „Położenie nieznane” zamiast „Położenie bramy: nieznane”.
- Żadnych operacji BLE ani I/O w `onGetTemplate()` — tylko odczyt ostatniego modelu.
- Koniec projekcji nie zmienia łącza do sterownika (spec 5.2): nie woła `disconnect` ani `uiDetached` poza cyklem życia ekranu.
- Repozytorium bez git: zadanie kończy zielony test wskazany w zadaniu; pełny zestaw na końcu: `./gradlew :protocol:test :domain:test :ble:testDebugUnitTest :car:testDebugUnitTest :app:testDebugUnitTest :app:assembleDebug -q` bez ostrzeżeń kompilacji w nowym kodzie.

## Punkty uwagi przy review

1. Wynik OPEN z poprzedniego pobytu przy bramie nie ukrywa nowego powiadomienia → Zadanie 4, `previousCycleResultDoesNotHideNewCycle`.
2. Koniec projekcji przy komendzie w toku — powiadomienie znika, komenda trwa (domena) → Zadanie 4, `projectionEndHidesWithoutTouchingCommand`.
3. Host z limitem 1 wiersza — stan połączenia, położenie i reguła w jednym wierszu → Zadanie 3, `rowLimitOneCombinesTopPriorities`.
4. Brak konfiguracji lub zablokowane poświadczenie — „Skonfiguruj aplikację…” bez przycisków → Zadanie 3, `configureOnPhoneHasNoActions`.
5. Chwilowa utrata łącza w zasięgu — powiadomienie widoczne bez przycisku, przycisk wraca w READY → Zadanie 4, `transientLinkLossKeepsNotificationWithoutButton`.

### Zadanie 4: Polityka powiadomienia w samochodzie

**Pliki:** `car/src/main/kotlin/.../CarNotificationPolicy.kt`; test `CarNotificationPolicyTest.kt`.

**Interfejsy — produkuje:** `data class CarNotification(val title: String, val lines: List<String>, val showOpen: Boolean)`; `class CarNotificationPolicy { fun update(s: GateUiState, projecting: Boolean): CarNotification?; fun onDismissedByDriver() }`.

**Reguły (`doc/car_design.md` §4.2):**
- Cykl zaczyna się przy przejściu `presence` do SHOWN: zapamiętaj `s.lastCommand` (referencja), wyzeruj „zamknięte”.
- „Zamknięte”, gdy `lastCommand` różny od zapamiętanego, `command is GateCommand.Open` i `outcome == OUTPUT_TRIGGERED`, albo po `onDismissedByDriver()`.
- Wynik: `null`, gdy `presence != SHOWN`, `!projecting` albo zamknięte. Inaczej:
  - linie: połączenie, „Położenie nieznane”, wynik ostatniej komendy tylko z tego cyklu (lastCommand różny od zapamiętanego), przez `Texts.car`;
  - `showOpen = s.notificationActionsAvailable`.

- [ ] Testy (RED):
  - `showsWhenShownAndProjecting`;
  - `hiddenWithoutProjection`;
  - `openButtonOnlyWhenActionsAvailable`;
  - `confirmedOpenInCycleHides` (także OPEN z telefonu);
  - `closeResultDoesNotHide`;
  - `busyOrUnknownKeepsWithResultText`;
  - `previousCycleResultDoesNotHideNewCycle` (lastCommand OUTPUT_TRIGGERED OPEN przed wejściem w SHOWN → widoczne, bez tekstu wyniku);
  - `newCycleAfterHiddenShowsAgain`;
  - `transientLinkLossKeepsNotificationWithoutButton`;
  - `projectionEndHidesWithoutTouchingCommand`;
  - `driverDismissHidesUntilNextCycle`;
  - `quietHides` (SHOWN → QUIET).
- [ ] Implementacja.
- [ ] `./gradlew :car:testDebugUnitTest -q` — PASS.
